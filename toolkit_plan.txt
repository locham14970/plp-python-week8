PERSONAL MINI-TOOLKIT PLAN

1. TOOLS

Tool 1: Simple Calculator
The calculator allows the user to perform basic addition, subtraction, multiplication, and division.

Tool 2: To-Do List
The to-do list allows the user to add tasks, view tasks, and remove tasks while the program is running.

Tool 3: Number Guessing Game
The number guessing game asks the user to guess a secret number and gives feedback until the correct number is guessed.

4. PROGRAM FLOW

The program starts with a welcome message.
The menu is displayed to the user.
The user selects a tool.
The selected tool runs.
After the tool finishes, the menu appears again.
The program continues until the user chooses Quit.
If the user enters an invalid choice, the program displays a polite error message and shows the menu again.
