# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that provides three useful tools through a simple menu. The tools are a Simple Calculator, a To-Do List, and a Number Guessing Game. The program uses variables, input and output, conditionals, loops, lists, functions, and f-strings.

## Tools

### 1. Simple Calculator

The calculator performs addition, subtraction, multiplication, and division.

### 2. To-Do List

The to-do list allows the user to add, view, and remove tasks while the program is running.

### 3. Number Guessing Game

The number guessing game allows the user to guess a secret number and gives feedback until the correct number is found.

## How to Run

Make sure Python is installed on your computer.

Open the project folder in VS Code and run:

```text
py toolkit.py
```

Follow the menu instructions to use the different tools.

## Reflection

The hardest part of this project was connecting the individual tools to one main menu. I had to make sure that the menu returned after each tool finished. The bug that took the longest to fix was the indentation error in the main menu loop. I learned that Python uses indentation to determine which statements belong inside a loop. Working with the to-do list helped me understand how lists can change while a program is running. I also became more comfortable using loops and conditionals together. If I had one more week, I would add more tools and save the to-do list so that tasks could be kept after the program closes.
